# Kleiderspenden Portal

Diese Webanwendung ermöglicht die Registrierung einer Kleiderspende.

## Funktionen

* Auswahl der Übergabeart (Geschäftsstelle oder Abholung)
* Auswahl der Kleidungsart
* Auswahl des Krisengebiets
* Formularvalidierung mit JavaScript

## Technologien

* HTML
* CSS
* JavaScript
* GitHub Pages
